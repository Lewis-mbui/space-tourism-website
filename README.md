# Space Tourism Website

## Overview

The Space Tourism Website is a responsive multi-page web application built as part of a Frontend Mentor challenge. The application allows users to explore destinations, crew members, and space technologies through an interactive interface inspired by modern space tourism concepts.

The project was built with **React**, **TypeScript**, and **React Router**, with a focus on component reusability, accessibility, and responsive design. Application content is sourced from a structured JSON dataset and rendered dynamically, allowing the interface to update based on user interactions without requiring page reloads.

Throughout the project, I practiced building a scalable component architecture, implementing nested routing with shared layouts, managing UI state with React hooks, and applying accessibility best practices such as ARIA attributes and keyboard navigation.

## Features

### User Features

- Explore information about space destinations.
- Browse profiles of crew members.
- Learn about space technologies and launch systems.
- Navigate seamlessly between sections using client-side routing.
- Experience responsive layouts optimized for mobile, tablet, and desktop devices.

### Technical Features

- Built with **React** and **TypeScript**.
- Nested routing using **React Router**.
- Shared layout architecture with route-based page theming.
- Dynamic content rendering from a local JSON data source.
- Reusable and composable component structure.
- Accessible navigation with ARIA attributes and screen-reader support.
- Keyboard navigation support for destination tabs.
- Responsive image delivery using the <picture> element and multiple image formats.
- Type-safe data models and route configuration.

## Technologies Used

- **React** – Component-based UI development.
- **TypeScript** – Static typing and improved developer experience.
- **React Router** – Client-side routing and layout-based navigation.
- **Vanilla CSS** – Responsive layouts, theming, and component styling.
